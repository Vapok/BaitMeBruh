# 1.0.0 - Initial Release
* Added Primitive Fishing Rod craftable at Workbench level 1 with custom model and icon.
* Added dynamic line tension system replacing flat stamina drain.
* Added casting gauge with distance readout and tap casting.
* Added quick bait switching with G (keyboard) or Right Bumper (gamepad).
* Added dynamic in-game key hints for keyboard and gamepad.
* Added audio, splash, and strike banner cues when fish bite.
* Added seated fishing and boat trolling support.
* Added Bait Creels and passive Coastal and Deep-Sea Fish Nets.
* Added recipes to craft all biome baits at the Workbench and Cauldron.
* Added roasted fish cooking over campfires and Trollfish Chowder at the Cauldron.
* Added translations for all 34 supported languages.
* Added comprehensive configuration options for all mod features.
* Built against Jotunn 2.30.2 and internal dependencies for stability.
